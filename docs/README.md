# 文件索引

文件分成**對外**與**內部**兩組。分的依據不是機密等級，而是
**讀者手上有什麼、需要知道什麼**：

- **對外**（`external/`）—— 給對接廠商。他們手上只有一把 API Key 與一份規格，
  不需要也不應該知道資料表長什麼樣、排程幾點跑、哪個查詢會慢。
- **內部**（`internal/`）—— 給開發與維運。包含架構取捨、資料模型、
  部署與排錯，其中很多是「為什麼不這樣做」的記錄。

> **這個 Demo 的兩份文件都在公開的 repo 裡**，因為它本來就是拿來展示作法的。
> 正式專案不會這樣：`internal/` 會留在私有 repo，只有 `external/` 隨交付出去。
> 文件內容從頭到尾都是示範資料（示範工程公司、示範市政府建設局），
> 沒有任何真實客戶、案件或設定。
